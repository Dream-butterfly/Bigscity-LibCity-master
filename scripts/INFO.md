# scripts/INFO.md

工程脚本集合，承载三类能力：主运行入口、运维/排障工具、独立实验入口。

## 关键子目录

| 目录 | 作用 |
| --- | --- |
| `run/` | 命令行运行入口（数据处理/训练/续训/评估/调参），也被 Web 后端通过 subprocess 调用 |
| `tools/` | 检查与维护脚本（依赖、配置、缓存、冒烟） |
| `experiments/` | 与主 pipeline 解耦的独立实验脚本（用于新模型快速验证） |

## 输入/输出

- **输入**：命令行参数、配置文件、`resource_data/` 数据和已有缓存/工件
- **输出**：训练产物（`outputs/<exp_id>/`）、数据工件（`cache/data_artifacts/`）、清理日志

## 调用关系

1. `run/` 被开发者直接调用，也被 Web 后端间接调用
2. `tools/` 通常由开发者手动触发，用于诊断和维护
3. `experiments/` 主要服务实验性模型，不保证与主流水线参数完全一致

## 修改注意事项

1. 新增或修改脚本参数时，同步更新对应 INFO.md 与根 INFO.md 示例命令
2. 所有脚本保持”从仓库根目录可执行”，避免隐式工作目录依赖
3. 涉及删除/重建缓存的脚本必须限制作用目录，禁止默认波及 `outputs/`
4. 对外可调用脚本应保持参数兼容，减少 Web 侧和自动化流程改造成本
