# scripts/tools/INFO.md

## 目录职责

`scripts/tools/` 提供工程运维与调试脚本，帮助快速定位“依赖、配置、数据、缓存、前向可用性”等问题。

## 关键脚本

| 文件 | 作用 |
| --- | --- |
| `check_deps.py` | 检查核心与可选依赖可用性 |
| `clear_cache.py` | 按策略清理缓存目录 |
| `inspect_config.py` | 打印配置合并后的最终参数 |
| `inspect_dataset.py` | 检查数据加载、shape 和基础统计 |
| `rebuild_dtw_cache.py` | 清理并重建 DTW 缓存 |
| `smoke_test.py` | 单批次/短流程冒烟执行，快速验证链路可用 |

## 输入/输出

- **输入**：模型/数据集标识、配置覆盖参数、缓存路径。
- **输出**：终端诊断信息、缓存状态变化、简要验证结果。

## 调用关系

1. 默认由开发者手工触发，不作为训练链路的强依赖步骤。
2. 脚本内部复用 `GNNTP` 的配置解析、数据构建和模型初始化能力。

## 修改注意事项

1. 工具脚本优先保证“失败可解释”，报错信息要指向具体问题。
2. 任何删除操作必须限定目录范围，避免误删 `outputs/` 或源码文件。
3. 输出格式尽量稳定，便于 Web 或自动化流程解析。
4. 新增工具时需在本文件补充适用场景和最小示例命令。
