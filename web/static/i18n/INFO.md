# web/static/i18n/INFO.md

## 目录职责

Web 控制台国际化翻译文件（JSON 格式）。前端 JS 通过 `t('key')` 函数按当前语言加载对应翻译。

## 关键文件

| 文件 | 语言 | 大小 |
| --- | --- | --- |
| `zh-CN.json` | 简体中文 | 11.7 KB |
| `en-US.json` | 英语（美国） | 12.1 KB |
| `ja-JP.json` | 日语 | 13.4 KB |

## JSON 结构

```json
{
  "section": {
    "key": "翻译文本",
    "key2": "翻译文本2"
  }
}
```

Key 为点分隔的层级结构，对应 JS 中 `t('section.key')` 调用。

## 输入/输出

- **输入**：前端 JS 通过 `t()` 函数查询 key
- **输出**：当前语言对应的翻译文本

## 调用关系

1. `../main.js` 加载 JSON 文件初始化 i18n 实例
2. 语言切换时重新加载对应 JSON 文件

## 修改注意事项

1. 三个语言文件的 key 结构必须完全一致
2. 新增翻译 key 必须同步补充所有语言版本
3. 翻译文本中 HTML 标签需转义或保留
4. 占位符使用 `{0}`, `{1}` 格式
