# ai_logs/change/INFO.md

## 目录职责

存放每次代码修改的变更记录，按 `YYYY-MM/` 月度目录组织。每条记录遵循 `AI_LOGS_MAIN.md` 定义的模板。

## 目录结构

```
change/
├── INFO.md
├── 2026-04/
│   ├── <date>_<简述>.md
│   └── ...
└── 2026-05/
    └── ...
```

## 记录模板

每条变更记录包含：
- 日期与编号
- 变更类型（新增/修改/修复/重构）
- 变更摘要
- 详细变更（逐项）
- 影响范围（文件列表）
- 验证方式

详见 `../AI_LOGS_MAIN.md` 完整模板。

## 输入/输出

- **输入**：AI 完成代码修改后的 diff 和说明
- **输出**：按月度归档的 `.md` 变更记录

## 修改注意事项

1. 归档后不修改历史记录
2. 命名规范：`YYYY-MM-DD_<简要描述>.md`
3. 来源必须标注（AI 协助 / 人工 / 混合）
