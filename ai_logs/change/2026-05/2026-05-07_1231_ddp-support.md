# 更改 17: 多卡训练 DDP 支持

> 日期: 2026-05-07 | 类型: 新增功能/结构重构 | 文件: 14

## 概述
为 GNN-TP 添加 `torchrun` + `DistributedDataParallel` (DDP) 多卡训练支持，向后兼容单卡模式。DDP 对卡数透明（2/4/8 卡同一套代码）。

## 改动清单

### Phase 1: 基础设施层
| 文件 | 改动 | 行数 |
|------|------|------|
| `utils/argument_list.py` | 新增 `local_rank`, `world_size`, `dist_backend`, `scale_lr` 4个CLI参数 | +20 |
| `config_parser.py` | `_init_device()` 重写：检测 `LOCAL_RANK` 环境变量自动切换 DDP 模式，LR 线性缩放 | +64/-9 |
| `data/dataloader.py` | `generate_dataloader` / `generate_dataloader_pad` 增加 `sampler` 参数 + `pin_memory` | +41/-16 |
| `data/runtime.py` | 新增 `_make_ddp_samplers()` 辅助函数，`build_artifact_runtime` 注入采样器 | +30/-1 |
| `data/dataset/mixins/pipeline_mixin.py` | `_generate_data()` DDP 下创建 DistributedSampler | +17/-1 |

### Phase 2: 训练核心
| 文件 | 改动 | 行数 |
|------|------|------|
| `common/traffic_state_executor.py` | 10处修改：`is_distributed` 标记、`_unwrap_model/_is_rank0/_barrier` helpers、GradScaler/autocast 去硬编码、save/load 模型走 `_unwrap_model`、hyper_tune rank guard | +60/-10 |
| `pipeline.py` | 新增 `_maybe_wrap_ddp()`，`run_model`/`objective_function` 加入 DDP 包装 + rank guard + cleanup | +57/-5 |
| `scripts/run/run_train_artifact.py` | 新增 `_maybe_wrap_ddp()` + rank guard + cleanup | +87/-30 |

### Phase 3: 模型修复（register_buffer）
| 文件 | 问题 | 修复 |
|------|------|------|
| `STGCN/model.py` | `self.Lk` 为普通 tensor，`model.to(device)` 不移动 | → `register_buffer('Lk', ...)` |
| `STTN/model.py` | `self.adj_mx` 同上 + forward 中重新赋值破坏 buffer | → `register_buffer` + 局部变量替代 |
| `PDFormer/model.py` | `far_mask/geo_mask/sem_mask/pattern_keys` 为普通 tensor | → `register_buffer` |

### Phase 4: 子 Executor 适配
| 文件 | 改动 |
|------|------|
| `STGformer/executor.py` | `sampler.set_epoch()` + `all_reduce` loss 平均 + rank guard + `_unwrap_model` |
| `DCRNN/executor.py` | 同上 |
| `PDFormer/executor.py` | 同上 + `load_model_with_initial_ckpt` 走 `_unwrap_model` |

## 向后兼容
- 非 `torchrun` 启动时（无 `LOCAL_RANK` 环境变量），完全退化为原有单卡逻辑
- 模型 save/load 格式不变（单卡/DDP 互加载兼容）
- `find_unused_parameters=False`（性能最优），`scale_lr=True`（默认 LR 线性缩放）

## 启动方式
```
# 单卡（不变）
python run_model.py --gpu_id 0

# 多卡（DDP）
torchrun --nproc_per_node=4 run_model.py
torchrun --nproc_per_node=4 scripts/run/run_train_artifact.py
```
