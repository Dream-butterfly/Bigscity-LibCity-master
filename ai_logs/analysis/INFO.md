# ai_logs/analysis/INFO.md

## 目录职责

存放代码分析报告，按 `YYYY-MM/` 月度目录组织。用于记录深度代码审查、架构分析、性能分析等非变更类工作。

## 目录结构

```
analysis/
├── INFO.md
├── 2026-04/
│   ├── <date>_<主题>.md
│   └── ...
└── 2026-05/
    └── ...
```

## 记录内容

分析记录可包含但不限于：
- 模型代码深度分析（创新点/漏洞/冗余/改进建议）
- 架构审查报告
- 性能瓶颈分析
- 代码规范合规检查
- 重构方案评估

## 输入/输出

- **输入**：AI 完成的代码分析结果
- **输出**：按月度归档的分析报告 `.md`

## 修改注意事项

1. 分析记录为只读归档，不做后续修改
2. 建议与变更记录（`../change/`）交叉引用
3. 命名规范：`YYYY-MM-DD_<分析主题>.md`
