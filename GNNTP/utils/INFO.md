# utils/INFO.md

## 目录职责

`utils/` 提供跨模块通用能力：参数解析、随机性控制、路径与日志管理、归一化工具、DTW 与调参辅助函数。

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `utils.py` | 路径管理、`exp_id` 生成、logger、模型/执行器构建等基础工具 |
| `argument_list.py` | CLI 通用参数定义与 `add_general_args` 扩展 |
| `dataset.py` | 时间与坐标等数据辅助处理 |
| `normalization.py` | 多种归一化器实现 |
| `dtw.py` | DTW 相关计算与缓存辅助 |
| `tune.py` | 调参过程辅助逻辑 |
| `disturbance.py` | 扰动/噪声注入工具 |

## 输入/输出

- **输入**：配置对象、路径参数、数据张量或统计信息。
- **输出**：统一格式的工具结果（目录路径、logger、归一化对象、转换结果等）。

## 调用关系

1. `scripts/run`、`pipeline.py`、`common/`、`data/`、`models/` 都会直接或间接调用本目录。
2. `utils.py` 是实验路径和日志落盘的核心依赖层。

## 修改注意事项

1. 公共方法改名或签名变更会影响全局，必须先检查所有调用点。
2. 路径规则（`outputs/`、`cache/`、`exp_id`）变更要兼容历史目录结构。
3. 工具层避免引入任务或模型专属逻辑，防止循环依赖。
4. 新增 CLI 通用参数时需与 run 入口、Web 映射和配置解析保持一致。
