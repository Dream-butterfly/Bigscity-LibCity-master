# data/INFO.md

## 目录职责

`data/` 负责从原始数据到可训练批数据的完整转换：数据集实例化、切分、归一化、DataLoader 构建与数据特征生成。

## 关键文件与目录

| 路径 | 作用 |
| --- | --- |
| `factory.py` | 根据配置构建具体数据集对象 |
| `registry.py` | 数据集名称到类实现的注册与定位 |
| `dataloader.py` | 批加载逻辑封装 |
| `artifact_io.py` | 数据工件（artifact）读写、签名与严格校验 |
| `dataset/` | 具体数据集实现（交通状态、交通流等） |
| `core/` | 底层数据结构（Batch、ListDataset） |

## 输入/输出

- **输入**：`resource_data/` 原始文件和数据相关配置（窗口、切分比例、归一化策略等）。
- **输出**：`train/valid/test` 数据迭代器与 `data_feature` 字典（供模型构建使用）。

## 调用关系

1. `pipeline.py` 和 `run_data_prep.py` 会调用本目录完成数据构建。
2. `dataset/` 决定任务/模型适配的数据逻辑，`core/` 提供底层承载。
3. 产物被 `models/` 和 `common/` 直接消费。

## 修改注意事项

1. 新增数据集实现后必须接入注册机制，否则无法按名称加载。
2. 字段名与 shape 改动要同步检查模型输入约定和执行器读取逻辑。
3. 缓存格式变更需考虑历史缓存兼容或提供重建路径。
4. 保持数据预处理逻辑可复现（随机切分、归一化统计口径要稳定）。
