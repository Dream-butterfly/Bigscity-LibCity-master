# GNNTP/data/core/INFO.md

数据层基础抽象，确保上层数据集实现以统一结构产出批数据。

## 关键文件

| 文件 | 作用 |
|------|------|
| `batch.py` | 批数据容器与字段组织逻辑 |
| `list_dataset.py` | 列表样本到 PyTorch Dataset 结构的封装 |

## 输入/输出

- **输入**：样本列表、字段定义、批次索引
- **输出**：规范化 batch 对象（dict 结构），供 DataLoader → 模型/执行器读取

## 调用关系

1. `data/dataloader.py` 依赖本目录完成批构建
2. `data/dataset/*` 的上层数据实现通过本目录统一输出结构

## 修改注意事项

1. 变更 batch 字段结构前，需排查所有模型对字段名/shape 的读取逻辑
2. 保持默认行为稳定，避免影响历史模型和测试脚本
3. 字段命名改动必须同步更新相关评估与可视化逻辑
