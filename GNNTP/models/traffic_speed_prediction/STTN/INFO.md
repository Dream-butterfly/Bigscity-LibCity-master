# STTN/INFO.md

## 目录职责

实现 STTN 模型，适配交通速度预测任务。

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `model.py` | STTN 模型结构与前向逻辑 |
| `config.json` | 默认超参数 |
| `manifest.json` | 模型注册元信息 |

## 输入/输出

- **输入**：交通速度任务时空输入特征、训练配置。
- **输出**：预测结果、损失曲线和评估指标。

## 调用关系

1. 主流程通过模型注册定位并实例化本目录模型。
2. 训练与评估由 `common` 层执行器调度。

## 修改注意事项

1. 模型结构改动需同步检查 `config.json` 默认参数是否仍合理。
2. 输出 shape 变更要同步检查执行器与评估器读写逻辑。
3. 参数新增需保持与配置文件读取键一致。
