# lib/INFO.md

## 目录职责

`lib/` 提供 STGformer 独立实现的底层依赖，包括数据准备、图算法、指标计算和通用工具。

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `data_prepare.py` | 数据读取、预处理与训练输入构建 |
| `graph_algo.py` | 图结构相关算法与邻接处理 |
| `metrics.py` | 评估指标实现 |
| `utils.py` | 通用辅助函数 |

## 输入/输出

- **输入**：原始或中间态时空数据、图结构信息和配置参数。
- **输出**：训练可用数据结构、指标函数结果和通用计算结果。

## 调用关系

1. 被 `../model/train.py` 与 `../model/STGformer.py` 调用。
2. 是独立实现中数据和评估逻辑的核心支撑层。

## 修改注意事项

1. 函数签名改动需同步检查 `model/` 所有调用点。
2. 指标口径变更要明确记录，便于与主框架结果对齐对比。
3. 数据预处理行为改动应与模型输入约定保持一致。
