# model/INFO.md

## 目录职责

该目录承载 STGformer 独立版的模型主体与训练入口。

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `STGformer.py` | 模型网络结构定义 |
| `train.py` | 独立训练启动脚本 |
| `STGformer.yaml` | 训练与模型参数配置 |

## 输入/输出

- **输入**：`lib/` 提供的数据处理结果、YAML 参数和命令行覆盖参数。
- **输出**：训练日志、checkpoint、预测结果和评估指标。

## 调用关系

1. `train.py` 调用本目录模型实现。
2. 训练过程依赖同级 `../lib` 的工具函数与指标实现。

## 修改注意事项

1. YAML 参数键名改动需同步更新 `train.py` 的读取和默认值逻辑。
2. 模型输入 shape 变更要同步修改数据准备逻辑和训练脚本组 batch 过程。
3. 与框架版做对照实验时，务必记录参数口径和训练策略差异。
