# new/INFO.md

## 目录职责

`models/new/` 存放新增或实验性模型实现，用于快速迭代验证，不影响稳定模型目录。

## 关键子目录

| 目录 | 作用 |
| --- | --- |
| `NEW_MODEL/` | 新模型接入模板 |
| `new_diffusion/` | 扩散类实验模型实现 v1 |
| `new_diffusion_2/` | 扩散类实验模型实现 v2 |

## 输入/输出

- **输入**：数据批次、模型配置和实验参数。
- **输出**：预测结果、损失及训练中间状态。

## 调用关系

1. 可通过 `models.registry/locator` 接入主流程加载。
2. 也可能被 `scripts/experiments` 独立脚本直接调用。

## 修改注意事项

1. 实验模型稳定后应沉淀注册信息、配置说明和目录文档。
2. 保持 `config.json`、`manifest.json`、代码参数读取名一致。
3. 明确“仅实验”与“可上线主流程”模型状态，避免误用。
