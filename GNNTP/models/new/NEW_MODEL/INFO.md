# NEW_MODEL/INFO.md

## 目录职责

`NEW_MODEL/` 是新模型接入模板目录，用于验证“模型代码 + 配置 + 注册”接线是否完整。

## 关键文件

| 文件 | 作用 |
| --- | --- |
| `model.py` | 模型模板实现 |
| `config.json` | 默认参数模板 |
| `manifest.json` | 模型注册元信息模板 |

## 输入/输出

- **输入**：标准任务批数据与配置参数。
- **输出**：预测结果（由执行器继续计算损失和评估）。

## 调用关系

1. 复制并重命名后，可通过 `models.registry` 接入主流程。
2. `pipeline.py` 通过模型定位器实例化该模板衍生模型。

## 修改注意事项

1. 使用该模板新建模型时，必须同步更新目录名、模型名和 `manifest.json`。
2. 参数键名保持配置文件与 `model.py` 读取一致。
3. 模板代码仅用于起步，正式模型需补充完整文档与测试。
